# Source provenance

The `source-mirror-import` branch contains a file-for-file copy (256 paths)
of https://gitlab.com/yuanzhongqiao3601/ai-comic-factory at its `main` branch,
plus three pre-existing GitLab scaffold automation/docs files.
That third-party mirror reports `@jbilcke/comic-factory` v1.2.3.
It is not verified to be identical to the original GitHub archive as of 2025-10-31.
Files were copied through the GitLab API, not by Git push, so original Git history
has not been imported. Original LICENSE/LICENCE.md and attribution are retained.
